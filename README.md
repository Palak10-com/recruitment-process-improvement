# Recruitment Process Improvement | Business Analysis Case Study

## Project Overview
This project analyzes a hypothetical recruitment scenario at Zen Yoga Studio, a startup wellness business based in Gurugram. The case study applies Business Analysis techniques to identify potential recruitment inefficiencies and propose an improved hiring workflow.

## Included Files

| File Name | Description |
|---|---|
| `RECRUITMENT PROCESS IMPROVEMENT.pdf` | Documents the recruitment process improvement case study, including the business problem, root cause analysis, As-Is and To-Be processes, and conclusion. |
| `Zen Yoga Studio Business Overview.pdf` | Presents the business background, mission, vision, target customers, competitors, and business needs of Zen Yoga Studio, Business process. |
| `Fishbone Diagram` | Illustrates potential causes of recruitment inefficiencies using cause-and-effect analysis. |
| `5 Whys Analysis` | Explores the underlying causes of the recruitment problem by repeatedly asking why. |
| `As-Is Recruitment Process` | Maps the recruitment workflow before the proposed improvements. |
| `To-Be Recruitment Process` | Maps the proposed improved workflow, including standardized screening, an online test, two interview rounds, and centralized candidate tracking. |

## Tools Used
Tools: Lucidchart, Google Docs, Microsoft Word

## Expected Outcomes

Reduced recruitment delays

Improved application tracking

More consistent candidate evaluation

Less repetitive manual work
